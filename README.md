# Our Movie Gallery 💗

Одностраничный сайт для нашего киноклуба: список фильмов «хотим посмотреть» и «посмотрели», ссылки на IMDb и Letterboxd, галерея-блокнот с фото (по одной странице на фильм), лента активности и фоновый плеер с тремя песнями.

## Как открыть

Просто откройте `index.html` в браузере. Ничего устанавливать не нужно.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на github.com (например, `our-movie-gallery`). Для бесплатного аккаунта Pages работает только с публичными репозиториями.
2. Загрузите в репозиторий все файлы из этой папки: `index.html`, `.nojekyll`, `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
5. Нажмите **Save**. Через минуту-две сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/our-movie-gallery/`

## Общий список (Supabase)

Фильмы, статусы, оценки, активность и фото хранятся в проекте Supabase. Изменения видны на всех устройствах, где открыт сайт.

- Таблица: `kino_state` (одна строка с id `main`).
- Фото: хранилище `photos` (публичный bucket).
- В `index.html` вверху скрипта указаны адрес проекта и publishable-ключ. Это публичный ключ, он безопасен для браузера; доступ контролируют правила (RLS) в Supabase.

Если нужно сменить проект, поменяйте `SUPABASE_URL` и `SUPABASE_KEY` в начале скрипта.

## Важно знать

- Без подключения к Supabase сайт работает локально, в браузере устройства.
- Фото загружаются с устройства (ссылки на Pinterest не работают).
- Музыка встроена в `index.html`, поэтому файл довольно большой (около 1,6 МБ). Это нормально для GitHub.
- Шрифты подгружаются из Google Fonts, для них нужен интернет.
